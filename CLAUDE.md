# Ghost Particle

Educational on-rails three.js game: ride one neutrino from the Sun's core to Super-Kamiokande.

Read in this order before doing anything:
1. `docs/DECISIONS.md` — index first; these are the rules. Add new decisions there.
2. `docs/FACTS.md` — the only place facts, figures, formulas, and image credits live. Never put a number anywhere else; reference the F-ID.
3. `docs/SPEC.md` — what we are building.
4. `docs/BEATS.md` — the moment-by-moment script. If it isn't there, it isn't built.
5. `docs/TODO.md` — what must be settled before coding.

No code exists yet. Do not scaffold until the open items in `docs/TODO.md` section 1 are decided.
